# Aygaz Dijital Arşiv

Aygaz'ın kurumsal arşiv kayıtlarının dijital ortamda kataloglanmasını, aranmasını ve yönetilmesini sağlayan arşiv sistemi.

## Özellikler

- Arşiv kayıtlarının kataloglanması
- Belge ve kayıt arama
- Kullanıcı ve yetki yönetimi
- Arşiv kayıtlarının takibi
- Zimmet ve iş kuyruğu yönetimi
- Saklama ve imha süreçleri
- Denetim izi
